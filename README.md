# LitePic

A minimal GitHub-based image host.

- Drag or select an image
- Upload directly to this repository's `images/` folder via GitHub API
- Copy Raw, jsDelivr, Markdown, or HTML links
- Token is kept in memory only and is never committed or stored in localStorage
- Static site deploys with GitHub Pages

## Usage

1. Open the Pages site.
2. Paste a GitHub fine-grained personal access token with **Contents: Read and write** access to this repository.
3. Drop an image onto the page.
4. Upload and copy the generated link.
